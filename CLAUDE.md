# KSE Hub — правила для Claude Code

Telegram-бот і Mini App для студентів KSE. Перед будь-якою роботою над інтерфейсом або повідомленнями бота:

1. Прочитай `PLAN.md` (що зроблено і що далі), `PRODUCT.md` (що і для кого) і `DESIGN.md` (як виглядає).
2. Подивись `design/refs/` і `design/refs/README.md`, user flow — `design/user-flow.html`.
3. Використовуй скіл `telegram-miniapp-design`.

## Як працюємо
- Спершу план екрана і питання, потім код. Якщо в PRODUCT.md немає відповіді — спитай.
- Перегляд без Telegram: `cd client && npm run dev`, відкрити `http://localhost:5173/?mock=1&theme=light` (або `dark`). Режим `?mock=1` підміняє `window.Telegram.WebApp` і API тестовими даними, працює лише в dev і до продакшну не потрапляє. `&state=empty|error` — порожній стан і помилка.
- Після кожного екрана — скриншоти у вбудованому браузері: 375 і 430 px, світла й темна тема. Знаходиш 3 слабкі місця й виправляєш.
- Існуючу логіку (OAuth, синхронізація Moodle, розклад, бронь) не ламаємо. Нове на сервері — лише додаванням (нові поля, нові ендпоінти), з тестом.
- Коміти маленькі: один екран або компонент — один коміт. Після кроку оновлюй `PLAN.md`.
